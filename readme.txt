HiringNeedsDesign is a single-page web application designed as a Music School Reporting Tool to help administrators track and manage hiring needs across multiple locations. The interface features a sidebar listing various school locations (Everett, Bellevue, Newcastle, etc.) with color-coded indicators (red for critical hiring needs, green for adequate staffing), and a main dashboard displaying teacher availability organized by instrument (Piano, Voice, Guitar, Drums, Violin) and day of the week. The tool provides interactive features including tooltips showing incoming and departing teachers, studio availability tracking, waitlist counts per day/instrument, hiring meeting comments, and a roster of current staff and potential hires with their qualifications. Built with HTML, Tailwind CSS, and vanilla JavaScript, it enables music school managers to quickly visualize staffing gaps, monitor waitlists, and track hiring progress across their organization.
