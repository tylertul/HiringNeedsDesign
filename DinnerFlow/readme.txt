DinnerFlow is a single-page web application designed to help users plan, organize, and manage their weekly dinner meals. The interface features a sidebar for navigating between weeks and meal categories, and a main dashboard displaying a weekly meal planner with drag-and-drop support. Users can browse a recipe library, add meals to specific days, track grocery lists automatically generated from planned meals, manage prep times, and save favorite meal plans as templates. Built with HTML, Tailwind CSS, and vanilla JavaScript, DinnerFlow makes weekly dinner planning simple, visual, and enjoyable.
